# AI-Based Medical Image Diagnosis & Symptom Prediction

## 📌 Overview
This repository presents a research-based implementation inspired by the published paper:
**“AI-Based Medical Image Classification and Symptom Prediction Using Deep Learning”**
published in the *International Journal of Innovative Research in Technology (IJIRT)*.

The project demonstrates how Convolutional Neural Networks (CNNs) and Natural Language Processing (NLP) techniques can be applied to assist medical image diagnosis and symptom-based disease prediction.

> ⚠️ Note: This repository provides a reference implementation and research reproduction framework. It does not represent the original experimental code used during publication.

---

## 📄 Publication
- Journal: International Journal of Innovative Research in Technology (IJIRT)
- Year: 2024  
- Paper Link: https://ijirt.org/Article?manuscript=181000

---

## 🧠 Problem Statement
Manual medical image analysis and symptom-based diagnosis can be time-consuming and prone to error. This project explores AI-driven approaches to improve diagnostic accuracy and reduce manual triage effort.

---

## 🏗️ Methodology

### 🔹 Medical Image Diagnosis
- Input: Medical images (X-ray / MRI / CT)
- Preprocessing: Normalization, resizing, augmentation
- Model: CNN-based classifier
- Output: Disease classification

### 🔹 Symptom Prediction (NLP)
- Input: Textual symptom descriptions
- Preprocessing: Tokenization, cleaning
- Feature Extraction: TF-IDF / embeddings
- Model: Classification-based symptom predictor

---

## 📊 Results (As Reported in Paper)
- CNN Image Classification Accuracy: **92%**
- NLP Symptom Prediction Reliability: **85%**
- Manual triage reduction: **~70%**
